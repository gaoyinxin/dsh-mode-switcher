# @gaoyinxin/dsh-mode-switcher

[English](README.md) | 中文

像 Claude Code 一样通过 `Tab` 键或工具栏按钮快速切换 **Plan** 和 **Build** 模式，并直接沿用输入框右侧原生的模型选择按钮自动记忆各模式的模型。

## 功能特性

- **键盘快捷键切换**：
  - 在输入框中随时按 `Tab` 键（无论是否已输入文字），立即在 `Build` 和 `Plan` 模式间平滑切换，完全不丢失已输入的草稿文本和光标位置。
  - 当 `@` 引用或 `/` 命令自动补全菜单弹出时，自动让位给补全选择。
- **工具栏统一控制按钮**：
  - 通过优先级遮蔽（`priority: -10`）接管 `conversation.input.plan` 槽位，替代原生单向的「计划」关闭按钮，避免按钮重复。
  - 常驻展示 `[ 🛠️ Build ⇥ Tab ]` / `[ 📋 Plan ⇥ Tab ]` 状态，点击即可切换。
- **沿用右侧原生模型选择器自动记忆**：
  - 无需额外的齿轮按钮或设置弹窗，直接使用输入框**右侧原生的模型选择按钮**即可。
  - 在 **Plan 模式**下通过右侧按钮选择的模型（含推理强度），会自动记忆为 **Plan 模式的专属模型**。
  - 在 **Build 模式**下通过右侧按钮选择的模型（含推理强度），会自动记忆为 **Build 模式的专属模型**。
  - 无论是按 `Tab` 键、点击按钮、输入 `/plan` 还是在计划评审卡片点击 `Approve`，在两个模式间切换时都会自动切回对应模式上次使用的模型。
- **原生双语支持**：
  - 自动识别系统语言，支持英文（English）与简体中文提示文本无缝切换。

## 安装方式

### 方式一：通过 DSH 插件市场（推荐）
1. 在 DSH 设置的 **插件 -> 发现** 中，点击 **管理索引源 -> 添加索引源**。
2. 输入市场索引地址：
   ```text
   https://gaoyinxin.github.io/dsh-mode-switcher/index.json
   ```
3. 在市场列表中搜索 **Mode Switcher**，点击 **安装** 即可。

### 方式二：命令行安装
```bash
dsh plugin add git+https://github.com/gaoyinxin/dsh-mode-switcher.git#v1.0.2
```
